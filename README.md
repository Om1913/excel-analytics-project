📊 Excel Pivot Table & Chart Analysis

This project demonstrates data analysis using Pivot Tables and Pivot Charts in Microsoft Excel / Google Sheets. The goal of the project is to analyze product exports, sales trends, and student performance data to extract meaningful insights.

📁 Project Overview

The dataset contains information related to product exports, orders, sales units, and student performance across different centers and modules. Using Excel’s data analysis tools, the raw data was organized, summarized, and visualized to better understand trends and patterns.

📊 Product Export & Sales Analysis

The following analysis was performed using Pivot Tables and Pivot Charts:

Calculated the total export quantity of each product.

Determined the percentage contribution of carrots to the total export quantity.

Analyzed how many times each product has been ordered and visualized the results using charts.

Identified the number of times Apple was ordered through pivot analysis.

Examined which countries placed orders for fruits and vegetables.

Calculated the percentage of fruit orders from the United States, New Zealand, and Australia.

Created a month-wise sales summary of each product.

Identified the top-selling product for each month using pivot charts.

Visualized the sales trend of Mango, Orange, and Apple across months.

📊 Student Performance Analysis

The project also includes analysis of student End Test performance across different centers and modules.

Key tasks performed:

Created a table showing how many students appeared for the End Test in each center.

Visualized the percentage distribution of performance categories using charts.

Analyzed the count of performance categories across different centers.

Calculated the percentage of Decline, Neutral, and Very Good performance for each center.

Identified the module with the highest decline percentage.

Calculated the average End Test score for each module in each center using a Pivot Table.
